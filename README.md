# MEMOR GROUP — сайт и админка

Корпоративный сайт строительной группы MEMOR GROUP: каталог объектов с фильтрами и картой,
страницы услуг, заявки с пересылкой в Telegram / почту / CRM и собственная админка.
Три языка: русский, узбекский, английский.

| Часть | Технологии | Папка |
|---|---|---|
| API, админ-API, интеграции | FastAPI, SQLAlchemy 2, Alembic, Pillow | `backend/` |
| Сайт и админка | Next.js 16 (App Router), React 19, Tailwind CSS 4, Leaflet | `frontend/` |
| База | SQLite для разработки, PostgreSQL в продакшене | |

Браузер всегда обращается к Next.js. Запросы `/api/*` и `/media/*` Next.js проксирует на FastAPI.
Поэтому cookie админки остаются на том же домене, а CORS не нужен.

## Запуск для разработки

Нужны Python 3.12+ и Node.js 20.9+.

```bash
cd backend
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt   # Linux/macOS: .venv/bin/python
.venv/Scripts/python -m alembic upgrade head
.venv/Scripts/python -m app.seed          # контент и фото из презентации и папок с материалами
.venv/Scripts/python -m uvicorn app.main:app --reload --port 8000
```

```bash
cd frontend
npm install
npm run dev
```

- Сайт: http://localhost:3000 (перенаправит на `/ru`)
- Админка: http://localhost:3000/admin. Логин и пароль первого администратора — `ADMIN_EMAIL` / `ADMIN_PASSWORD`
  в `backend/.env`. Сид создаёт этот файл сам со случайным паролем. После входа смените пароль в разделе «Пароль».
- Документация API (только при `DEBUG=true`): http://localhost:8000/api/docs

`python -m app.seed --reset` стирает весь контент (кроме пользователей и заявок) и заливает его заново.
Исходники для сида: папки с фото объектов и `.pptx` в папке `СЛАЙД`. Путь к ним задаёт `MATERIALS_DIR`,
по умолчанию это корень репозитория. Материалы хранятся в репозитории вместе с обработанными копиями
для сайта (`backend/media/`); базу с контентом, которая ссылается на эти копии, создаёт сид.

Тесты бэкенда: `cd backend && .venv/Scripts/python -m pytest`.

## Что есть на сайте

- **Главная**: слайдер реальных объектов, цифры компании, «Кто мы», услуги, подборка объектов,
  карта, спецтехника, «Почему нам доверяют», сертификаты (если опубликованы), форма заявки.
- **Объекты** (`/ru/projects`): фильтры по сектору, статусу, типу и городу, переключение плитка/карта.
  Состояние фильтров хранится в адресе страницы, так что выборкой можно поделиться ссылкой.
- **Страница объекта**: роль, заказчик, адрес, виды работ, галерея с вкладками
  «Проект / Строительство / Результат» и полноэкранным просмотром, точка на карте, похожие объекты,
  форма заявки с привязкой к объекту.
- **Услуги**: список услуг и страница каждой с объектами, где эта услуга выполнялась.
- **Дизайн-система** (`/ru/styleguide`): служебная страница с цветами, типографикой, кнопками, карточками, полями и иконками.
  Её нет в меню, поисковики её не индексируют. Из неё собрана страница «Дизайн-система» в макете Figma.
- **О компании**, **Контакты** (карта офиса, «Построить маршрут», форма).
- SEO: `sitemap.xml` с hreflang для трёх языков, `robots.txt`, canonical и Open Graph.
- Адаптивная вёрстка, проверена на 390, 768, 1024 и 1440 px. На телефоне внизу экрана есть панель
  «Позвонить / Оставить заявку». Карта не перехватывает прокрутку страницы: двигать её можно после первого касания.
  Админкой тоже можно пользоваться с телефона: заявки показываются карточками, фото переставляются стрелками.

### Связка с CRM MEMOR

CRM — отдельный проект (Django + React), рабочая копия в `../memor_crm`. Настраивается в «Интеграции → CRM MEMOR»:
адрес CRM и API-ключ партнёра (CRM: Настройки → API-ключи партнёров).

- **Заявки → CRM.** Каждая заявка с сайта уходит в `POST /api/public/applications/` (право ключа `CREATE_APPLICATION`).
  CRM находит клиента по телефону, склеивает повторы и заводит обращение и сделку с источником «Сайт».
  Результат («Обращение №…, сделка №…» или ошибка) виден у заявки в админке, есть повторная отправка.
- **Квартиры из CRM.** Переключатель «Показывать квартиры из CRM на сайте» включает раздел `/realty`:
  жилые комплексы, типы квартир, свободные квартиры с ценами. Ключу нужны права `VIEW_PROJECTS` и `VIEW_BUILDINGS`.
  Каталог забирается сервером сайта и кэшируется на 5 минут (`backend/app/crm_catalog.py`); если CRM недоступна,
  сайт показывает последний удачный снимок. Цены — только у свободных квартир, как их отдаёт CRM.
  Заявка со страницы комплекса уходит в CRM сразу с проектом.

Загруженные фото поворачиваются по EXIF, уменьшаются до 2000 px, сохраняются в WebP и получают
превью на 800 px. Имя файла — хэш содержимого, поэтому повторная загрузка того же снимка не создаёт копию на диске.

Защита: пароли хранятся в Argon2, сессия — JWT в httpOnly-cookie с SameSite=Lax. Изменяющие запросы
требуют заголовок `X-Memor-Admin` (защита от CSRF). Действуют лимиты на попытки входа и на заявки,
в форме есть скрытое поле-ловушка для ботов.

- **Лимиты и IP посетителя.** `X-Forwarded-For` читается, только если запрос пришёл от доверенного прокси
  (`TRUSTED_PROXIES`, по умолчанию `127.0.0.1,::1`), и справа налево — подделать адрес, дописав заголовок, нельзя.
- **Исходящие запросы (CRM, вебхук)** — защита от SSRF в `backend/app/outbound.py`: только `https://` и только
  публичные адреса (127.0.0.1, 10.x, 192.168.x, 169.254.x и т. п. запрещены), адрес проверяется при сохранении
  и ещё раз в момент соединения (DNS rebinding), редиректы не выполняются. Для разработки с CRM на этом же
  компьютере в `backend/.env`: `INTEGRATIONS_ALLOW_HTTP=true` и `INTEGRATIONS_ALLOWED_HOSTS=127.0.0.1,localhost`.
- **Заголовки безопасности:** страницы — CSP, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`,
  `Permissions-Policy`, HSTS (`frontend/next.config.ts`); ответы API и `/media` — строгий CSP `default-src 'none'`
  (`backend/app/main.py`). Новые внешние скрипты или iframe (виджеты, видео) нужно добавить в CSP в `next.config.ts`.
- **Выгрузка CSV:** ячейки, начинающиеся с `= + - @`, получают апостроф — Excel не исполнит их как формулу.

## Продакшен

1. PostgreSQL: задайте `DATABASE_URL=postgresql+psycopg://…` и выполните `alembic upgrade head`.
2. `backend/.env`: `DEBUG=false`, длинный случайный `SECRET_KEY`, `COOKIE_SECURE=true`, `MEDIA_DIR`, при необходимости SMTP.
   Если CRM MEMOR стоит в локальной сети, а не на публичном домене, — `INTEGRATIONS_ALLOWED_HOSTS=<её хост>`.
3. Бэкенд: `uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 2` (через systemd или supervisor).
   Бэкенд должен слушать только 127.0.0.1: IP посетителя берётся из `X-Forwarded-For` от локального прокси.
   Если прокси на другом хосте — укажите его в `TRUSTED_PROXIES` и в `--forwarded-allow-ips` uvicorn.
4. Фронтенд: `npm ci && npm run build && npm run start` с переменными `BACKEND_URL` и `SITE_URL`.
5. nginx перед Next.js:

```nginx
server {
    server_name memor.uz;
    client_max_body_size 40m;                 # пачки фото с телефона

    location /media/ {                        # картинки — напрямую с диска
        alias /var/www/memor/media/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        # Перезаписываем, а не дописываем: по этому IP работает лимит заявок и попыток входа.
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Подложка карт — тайлы OpenStreetMap. Для сайта с заметной посещаемостью лучше подключить
провайдера тайлов с ключом: URL задаётся в `components/site/ProjectsMap.tsx` и `components/admin/MapPicker.tsx`.
